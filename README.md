# KARDS VOX：KARDS 国家语音卡包

Windows 图形程序。主界面采用 KARDS 风格的旧纸卡、切角、暗色金属栏和印刷标签。日本包提供日语语音与日中双语字幕；苏联包提供俄语语音与俄中双语字幕；德国包提供德中字幕与 175 条德语录音。程序以**只读方式**读取 KARDS 的 Unreal 运行状态：只申请 `PROCESS_QUERY_INFORMATION | PROCESS_VM_READ`，不写游戏内存、不调用游戏函数，也不模拟鼠标键盘或修改游戏数值。

## 1.7.28 出牌彻底取消开场白

- 确认本方打出第一张牌时，立即停止当前开场声音和字幕，清除剩余开场队列，并取消本局尚未触发的自动开场。卡牌台词结束后不再恢复开场。
- 即使卡牌身份尚在匹配、该国没有录音或声音和字幕开关关闭，确认出牌仍会取消开场。只有新对局重置此状态；F6 主动预览仍可使用，下一次出牌会停止预览。
- 日苏德芬共用这条规则。`--intro-self-test` 验证延迟开场、队列、静音、跨国家出牌和下一局重置；保留原有攻击／受伤衔接。

## 直接使用

双击发布目录中的：

`KardsVox.exe`

程序可以在 KARDS 前后任意顺序启动，会每 500ms 自动等待并重连；KARDS 关闭后再次打开也不需要重启模组。当前设置默认开启自动播报和中文字幕，不需要截图、模板或校准。游戏时可以把主界面最小化。

- **自动识别国家**：程序从我方总部识别当前主国家，并独立识别每张牌的所属国家。混合卡组中的日本卡走日语语音和字幕，苏联卡走俄语语音和字幕；德国卡使用专属德中台词及对应德语录音，芬兰卡使用专属芬中台词及芬兰语录音；其余国家的卡显示本国卡名与中文提示。切换卡组或新开一局无需回软件切换。点击国家卡片只改变 F6 的预览目标。
- **界面“自动语音”开关 / F9**：开启或关闭当前国家的语音；字幕开关独立，关闭声音仍可显示字幕。
- **界面“双语字幕”开关**：开启或关闭日本、苏联及其他同盟国的游戏字幕，选择会保存。
- **界面“F6 指挥官预览”按钮 / F6**：始终预览界面选中的日本、苏联、德国或芬兰指挥官；即使在对局中，也不会改变战斗卡牌的国家识别。
- **F10**：输出当前连接、对局、牌桌、监听器和出牌队列状态，供排查使用。
- **F7/F8**：旧画面校准键，当前版本不再需要。

一次只运行一个 KARDS VOX 实例。点击主界面右上角关闭按钮即可退出。

## 双语字幕

日本指挥官开场字幕为：

> 同胞们，用各位的勇气与自信，为敌人带去恐惧吧，坚持战斗，直至最后一人！为敌人带去恐惧吧，屹立于此的勇士们啊！粉碎敌人的诡计阴谋吧！

纸条字幕沿用原来的纸卡外观，以原语言大字为主，中文小字附在下方。日本普通语音使用 `Data/Japan/voice_lines.tsv` 中已有的日中台词；124 张指令牌使用 `Data/Japan/order_originals.tsv` 的逐牌日文台词和 `order_lines.tsv` 的中文文案。逐牌台词采用短军令、电报和可核实的战时称谓，涉及登陆、舰队、补给、工厂与本土防卫；指令牌仍只播放合成电报音效，不播放人声。日本单独的长开场录音没有留存逐字日文稿，现有四段中文上方的日文是按该中文稿补写的字幕稿，尚未逐字核对录音。

苏联使用 `Data/Soviet/subtitle_lines.tsv` 中原创的俄中配对台词，按开场、单位类别、受伤和 HQ 战况触发；步兵、炮兵、骑兵、坦克、航空各有独立的轮换台词池。全部 119 张事件／指令牌的专属俄中台词收录在 `Data/Soviet/order_lines.tsv`，每张配有独立俄语录音。逐牌台词采用战时动员口号和简短军令；“预备役”使用“祖国母亲在召唤”的动员意象，“来自人民”配合卡牌造成伤害的效果改为炮弹攻击台词。这些是氛围台词，不是游戏卡牌效果译文或已有录音的转写。苏联开场白分为五段，录音合计约 23 秒，字幕按每段实际时长切换俄文和中文。字幕沿用图中的旧纸张、切角和印刷标签，显示在左下角玩家头像上方，并以纸片尾巴指向头像。字幕窗口不会获取焦点，也不会拦截鼠标。

两国的完整资源与游戏显示名对照分别见 `Data/Japan/card_titles.tsv` 和 `Data/Soviet/card_titles.tsv`。2026-09-24 从本机当前游戏包重新解出卡牌资产及中、英、日、俄本地化后，逐项核对了日本 312 个、苏联 319 个资产；所有 124/119 个指令资源都能对应到游戏标题。日本指令台词表中先前按英文资源名猜错的 98 个标题已按当前简体中文游戏文本纠正。少数没有独立标题的 `*_unlock*` 资源是总部解锁变体，在清单中明确标记。

## 触发方式

程序直接监听游戏已有的对象和事件数据：

- 对局开场：当只读状态机确认活动牌桌、双方 HQ 和起手牌已经建立时，按识别到的我方国家播放对应指挥官语音与字幕。若国家资源稍后才可读取，开场会等识别成功后播放。连接到已经进行的对局时，只有仍处于起手阶段才补上开场。同一局不重复触发。
- 对局结束：双方 HQ 离场后重置；新一局的 HQ 对象发生变化时也会建立新的对局编号，因此投降后连续开始下一局仍会再次播放开场。
- 打出手牌：监听游戏出牌队列、单位出牌动画与指令牌飞行动画。1.7.20 按实际 `BaseCardObject.CardID`（0x264）与动作编号逐张匹配，并核对所属玩家；指令牌即使没有单位动画标志也能通过 `ordersFlying` 和 `tmpCardID` 确认。`HandCardRef` 只有与当前出牌编号一致时才有效。手牌消失、弃牌、预览对象清理及旧引用均不能单独触发播报。
- 卡牌类别：日本目录收录 312 个资源，苏联目录收录 319 个资源；`Data/Allied/card_labels.tsv` 收录其他国家 1309 个资源及所属国家、卡种、原文和中文游戏标题。每张牌都按实际资源识别，未知归属时暂不播报，避免借用主国家台词。日本单位沿用原语音池；苏联单位按步兵、炮兵、骑兵、坦克、航空分别轮换对应的俄语语音与字幕。152 毫米榴弹炮和喀秋莎等炮兵牌不会再借用步兵台词。
- 防重复：日本步兵、炮兵、坦克、航空、海军五个部署池使用“洗牌袋”，分别有 17、6、10、16、7 条。步兵的部署、攻击和受伤不混入炮兵台词。实际对局优先读取游戏 `Type` 字段区分兵种，避免旧目录将 Ki-43 等飞机分入步兵。一个池里的所有素材没有播完前不会重复，下一轮第一条也不会和上一轮最后一条相同。
- 特殊指令：全部 124 张日本指令牌在 `Data/Japan/order_lines.tsv` 中各有独立中文标题和台词，`order_originals.tsv` 有配对的日文书面电文。指令牌不播放人声，只播放对应的合成电报声并显示双语字幕；手牌对象只会在明确确认本方出牌动画时触发。
- 盟国指令与单位：日苏卡组里打出的其他国家卡牌按游戏资源名确认。`Data/Allied/order_labels.tsv` 收录当前游戏包中 510 张其他国家指令牌的中文标题及效果；原文取卡牌所属国家的游戏标题。例如美国牌“团结就是力量”显示 `UNITY IS STRENGTH` 与中文标题和效果。其他国家的单位显示原文卡名及中文部署、攻击、受击或前移提示，暂不播放人声。
- 单位攻击：程序读取本方场上卡牌的 `lastAttackVisual` 引用变化，触发相应兵种的攻击台词。日本播放日语语音与双语字幕，苏联播放俄语语音与双语字幕。
- 单位前移：本方单位从支援阵线进入前线时触发一次移动语音与字幕。1.7.19 按游戏实际 `ECardLocationEnum` 修正为 `Board_HQLeft=5 → Board_Frontline=7`（4 是对方手牌），已知单位每 20 ms 检查位置，全场扫描作兜底；前线按单位所属玩家区分敌我。日本步兵与坦克使用现有日语移动录音，空军和海军使用相应的航路或出击录音；苏联使用各兵种已有的俄语前进、航行或就位录音；其他国家显示本国卡名和中文前移提示。重复采样不重复播报，撤回后再次前进可重新触发，启动时已在前线的单位不补播。
- 单位受伤：程序以 5 ms 频率读取本方场上单位的游戏伤害动画队列。日本单位直接播放日语受伤台词和相应字幕，不再先播放叫声音效；苏联单位播放俄语受伤台词和字幕。防御值变化保留为第二层兜底。
- 出牌去重：同一实际卡牌编号只消费一次出牌事件，重建视觉对象或重复读取动画不会再次播报；卡牌真正回到手牌后可再次出牌。不同编号不受全局冷却限制，连续打出同名轻步兵仍分别识别。
- 关键局势：从我方/敌方牌桌位置读取双方 HQ 的防御值，触发己方低血量、己方危急和敌方 HQ 危急提示。日苏两国均播报对应语音并显示字幕；阈值事件每局只触发一次。
- 播放顺序：第一张牌打出时立即结束开场白。连续出牌时，新卡通过约 180 ms 淡出接替旧台词，不必等上一张牌整句播完；淡出期间再次出牌只保留最新一张，不积压播报。攻击、受伤提示仍不能抢断当前出牌台词；新出牌清除过时的战斗提示，总部警报保留。新对局或离开对局时清空队列。日志记录事件与实际播放时间，便于核对延迟。
- 攻击／受伤独立打断：两种反应各保留一条最新待播提示，连续受击会合并，超过 3.5 秒的旧反应丢弃。攻击指令先保护约 1.45–2.2 秒，受击台词先保护约 1.05–1.45 秒，再允许另一种反应接替；具体保护时间随录音长度变化。接替前在录音中寻找短停顿，最多额外等 450 毫秒，然后用 180 毫秒淡出旧声音和文字，并淡入下一句。纸卡窗口保持显示，字幕与新声音同时开始。没有声音时也使用文字过渡。受击事件仍保留约半秒的归并窗口，给同次交战的攻击指令留出先出现的机会。

瞬时出牌引用与队列每 5 ms 读取一次；已知单位的移动每 20 ms 检查一次，全场卡牌对象每秒扫描一次作为兜底；活动牌桌对象每 5 秒刷新一次。投降、退出牌桌、关闭游戏或连接中断时，程序会立即停止正在播放的开场白并清除字幕。程序只读这些状态，用于处理出牌、投降、返回大厅和新一局对象重建。

## 日本语音素材

`Audio/Japan` 中有 144 个 WAV，索引位于 `Data/Japan/voice_lines.tsv`。文件格式为 48 kHz、单声道、16 位 PCM，使用原“日军”GPT-SoVITS 模型生成，没有使用“日军2”。

苏联 174 个俄语 WAV 位于 `Audio/Soviet`，包含 55 条开场、单位、战况语音与 119 条逐卡指令语音。台词表和资源统计见 [Data/Soviet/README.md](Data/Soviet/README.md)。

`JP_INF_Y_CHARGE_01` 已改用原始“日军”录音中的真人「天皇陛下」「万歳」表演并重新剪接，末尾保留 300 ms 自然尾音，不再使用 TTS 合成这一句。生成脚本会保护这条真人素材，使用 `--force` 也不会覆盖它；其他语音仍可用 `--id` 单独返修。

检查素材或试听指定语音：

```powershell
dotnet run -- --voice-check
dotnet run -- --play-jp JP_TANK_ATTACK_01
dotnet run -- --play-order-test
```

## 调试

启动后先看以下几行：

```text
Connected read-only to KARDS pid ...
Auto voice: ON
Runtime objects: board=0x...; battle monitor=0x...
```

起手换牌界面出现时应显示：

```text
MatchState: OutsideMatch -> InMatch (active battle board and both HQ objects ready)
Opening hand ready: playing commander_intro.wav
```

打出己方手牌后应显示卡牌 ID、游戏原声音和识别类别，例如：

```text
Own card played: id=...
Card ...: definition=..., original sound=..., pool=TANK, ...
Card ...: pool=TANK, playing JP_TANK_...
```

若游戏的瞬时 ID 队列在两次读取之间已经清空，单位牌会显示补偿确认日志：

```text
Unit deployed from hand: definition=..., original sound=..., pool=TANK, side=...
Unit deployed from hand: pool=TANK, playing JP_TANK_...
```

若自动播报关闭，按一次 F9。F10 可随时确认当前运行状态。

每次运行都会把连接、开局、出牌分类、去重和结束事件写入程序旁边的：

`logs` 文件夹

若程序所在目录不可写，则改存到 `%LOCALAPPDATA%\KardsVox\logs`。

遇到某张牌仍未播报时，退出程序后保留最新的日志即可直接定位其内部卡牌名和触发路径。

其他检查命令：

```powershell
dotnet run -- --status
dotnet run -- --runtime-snapshot
dotnet run -- --smoke
dotnet run -- --self-test
```
