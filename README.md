# KARDS VOX：KARDS 国家语音卡包

Windows 图形程序。主界面采用 KARDS 风格的旧纸卡、切角、暗色金属栏和印刷标签，按国家选择语音卡包。目前日本包可用，苏联包已建立卡牌目录与台本槽位，等待苏联语音模型和录音。程序以**只读方式**读取 KARDS 的 Unreal 运行状态：只申请 `PROCESS_QUERY_INFORMATION | PROCESS_VM_READ`，不写游戏内存、不调用游戏函数、不注入 DLL，也不模拟鼠标键盘，更不修改卡牌、资源或任何游戏数值。

## 直接使用

双击发布目录中的：

`KardsVox.exe`

程序可以在 KARDS 前后任意顺序启动，会每 500ms 自动等待并重连；KARDS 关闭后再次打开也不需要重启模组。当前设置默认开启自动播报和中文字幕，不需要截图、模板或校准。游戏时可以把主界面最小化。

界面状态会明确区分三个阶段：`等待 KARDS` 表示没有发现游戏窗口，`等待进入对局` 表示已发现 KARDS、但当前尚未加载活动牌桌对象，`已读取当前对局` 才表示只读监听器已经连接到本局牌桌。大厅、匹配和空牌桌过渡期间显示“等待进入对局”属于正常状态；进入有双方 HQ 的正式牌桌后会自动切换。

- **国家卡包选择**：日本包可播报；苏联包当前显示“待录音”，选择它会暂停语音和试听，不会借用日本语音。选择会保存。
- **界面“自动语音”开关 / F9**：开启或关闭当前可用卡包的自动播报，选择会保存。
- **界面“中文字幕”开关**：开启或关闭随语音显示的游戏字幕，选择会保存。
- **界面“F6 试听指挥官”按钮 / F6**：试听指挥官开场和完整字幕。
- **F10**：输出当前连接、对局、牌桌、监听器和出牌队列状态，供排查使用。
- **F7/F8**：旧画面校准键，当前版本不再需要。

一次只运行一个 KARDS VOX 实例。点击主界面右上角关闭按钮即可退出。

## 中文字幕

指挥官开场字幕固定为：

> 同胞们，用各位的勇气与自信，为敌人带去恐惧吧，坚持战斗，直至最后一人！为敌人带去恐惧吧，屹立于此的勇士们啊！粉碎敌人的诡计阴谋吧！

士兵与单位字幕来自 `Data/Japan/voice_lines.tsv` 中每条日语素材对应的中文台词。指挥官开场长台词会依次显示四句，确保完整显示“为敌人带去恐惧吧，屹立于此的勇士们啊！粉碎敌人的诡计阴谋吧！”。字幕采用接近 KARDS 卡牌界面的旧纸张、切角、印刷标签和日本红色标记，显示在左下角玩家头像上方，并以纸片尾巴指向头像。标签会按实际类别显示“陆军部队”“装甲部队”“航空队”“海军部队”或“通信兵”。字幕窗口不会获取焦点，也不会拦截鼠标。

## 触发方式

程序直接监听游戏已有的对象和事件数据。KARDS 当前版本会在运行时隐藏部分蓝图生成类名；读取器会从 `beingPlayFromHandCardIDs`、`IsMonitoring` 和 `selfBaseCardRef` 等稳定反射字段反向定位牌桌、监听器和可视卡牌基类，因此不再依赖已被隐藏的 `BP_*_C` 名称：

- 对局开场：当只读状态机确认双方 HQ 包装对象和本方起手牌已建立时，也就是起手换牌界面出现后，播放 `Audio/Test/intro.wav`。换牌阶段即使本方 HQ 的最终位置引用尚未填入也能触发；程序恰好在换牌阶段启动时会立即补播，连接到已经进入正式回合的对局时不会补播。同一局只播放一次，对局结束后状态机复位，下一局重新播放。
- 新牌桌发现：程序持续比较 Unreal 对象数量，只扫描本次新增的对象。新一局的牌桌对象创建后会立即接管并读取起手牌；即使游戏复用了旧对象槽位，等待对局期间每秒一次的精简牌桌检查也会兜底，不再受原先 5 秒刷新周期影响。
- 可见画面抢先触发：独立画面线程每 100 ms 检查一次前台 KARDS 的可见画面，不占用 5 ms 出牌监听。程序先看到匹配或加载画面并完成布防，随后起手换牌界面首次出现时便立即播放开场白；即使上一局投降后旧牌桌对象仍留在内存，新牌桌画面也会重置本局的一次性开关。内存状态稍后只负责确认本局并阻止重复。
- 对局结束：双方 HQ 离场后重置；新一局的 HQ 对象发生变化时也会建立新的对局编号，因此投降后连续开始下一局仍会再次播放开场。
- 打出手牌：在游戏自己的出牌动画标志升起时，立即读取 `HandCardRef`、`cardRef` 与 `tmpCurrentCard`，再由 `beingPlayFromHandCardIDs`、手牌离场和场上新增做确认兜底。程序使用牌桌自己的 `battleHudHasShown` 区分开局换牌和正式出牌；点击和选中手牌不会触发，真正开始出牌时才播放。
- 即时出牌：建立手牌基线后，只对本方约 4–10 个手牌可视对象以 5 ms 读取游戏自己的 `CardLocation`。单位从手牌位置切到牌桌位置、或指令牌在出牌动画开始时离开手牌，就立即开始对应语音；无需等待每秒一次的完整对象快照。点击、悬停和拖动尚未离开手牌位置时不会触发。
- 卡牌语音类别：`Data/Japan/card_catalog.tsv` 来自当前游戏资源清单，内置 312 个日本卡牌资源，其中 124 张事件牌全部进入指令池，其余单位严格分入 `INFANTRY`（步兵与炮兵）、`TANK`（坦克）、`AIR`（战斗机与轰炸机）、`NAVY`（海军）。即使游戏临时出牌引用没有名称，也会由手牌消失和出牌动画关联到对应卡牌，不再静默漏过。
- 防重复：四个部署池和指令池都使用“洗牌袋”。一个池里的所有素材没有播完前不会重复，下一轮第一条也不会和上一轮最后一条相同。当前部署池分别有 23、10、16、7 条，指令池有 9 条。
- 特殊指令：玉碎、帝国指令、武士之刃、扩张、为了繁荣、至死方休、两栖进攻、奇袭、空中闪击等指令由 `Data/Japan/order_profiles.json` 识别，全部绕过单位池，先播放短电报码，再从独立指令池播报；目录中的其余日本事件牌即使没有单独中文标签，也会自动进入通用指令池。若极短动画没有留在游戏队列中，程序还会使用正式出牌阶段中稳定确认的手牌减少进行补偿，不再漏掉“为了繁荣”一类指令。电报码与台词会先拼成兼容性更高的音频流，再交给系统播放，避免部分声卡只显示字幕却静音。
- 出牌去重：手牌和场上对象按内部卡牌名、原始音效与卡牌属性进行稳定匹配，不再把动画期间的对象地址重建误判成出牌。单位部署优先采用场上新增对象，指令采用手牌中真正减少的事件牌；同一次动作不会先播电报又被另一个类别的语音覆盖。匿名事件仅保留 180 ms 防抖，因此连续打出的两张牌不会被长时间窗口吞掉。
- 单位受伤：正式对局中每秒比较一次我方场上单位防御值。存活单位的防御下降时，根据步兵/炮兵、坦克、空军、海军类别，从独立 `HURT` 台词池选取日语受伤台词，并在前面加入一条短受伤声；范围伤害同一帧只播一次，避免多名单位同时受伤时声音堆叠。
- 关键局势：从我方/敌方牌桌位置读取双方 HQ 的防御值，触发己方低血量、己方危急和敌方 HQ 危急播报。阈值事件每局只触发一次。

瞬时出牌引用与队列每 5 ms 读取一次；可见开场画面由独立线程每 100 ms 检查一次；卡牌对象位置每秒检查一次作为兜底；活动牌桌对象每 5 秒刷新一次。投降、退出牌桌、关闭游戏或连接中断时，程序会立即停止正在播放的开场白并清除字幕。程序只读这些状态，用于处理出牌、投降、返回大厅和新一局对象重建。

## 日本语音素材

`Audio/Japan` 中有 144 个 WAV，索引位于 `Data/Japan/voice_lines.tsv`。文件格式为 48 kHz、单声道、16 位 PCM，使用原“日军”GPT-SoVITS 模型生成，没有使用“日军2”。

苏联资源统计、卡牌目录和待录制台本见 [Data/Soviet/README.md](Data/Soviet/README.md)。

`Audio/Sfx/Hurt` 中有 6 条短受伤声，来自 OpenGameArt 的 **Hurt Sound Effects**，作者 EZduzziteh，页面明确标注为 CC0。来源与授权记录位于 `THIRD_PARTY_NOTICES.md`。

`JP_INF_Y_CHARGE_01` 已改用原始“日军”录音中的真人「天皇陛下」「万歳」表演并重新剪接，末尾保留 300 ms 自然尾音，不再使用 TTS 合成这一句。生成脚本会保护这条真人素材，使用 `--force` 也不会覆盖它；其他语音仍可用 `--id` 单独返修。

检查素材或试听指定语音：

```powershell
dotnet run -- --voice-check
dotnet run -- --play-jp JP_TANK_ATTACK_01
dotnet run -- --play-order-test
dotnet run -- --play-hurt-test
```

## 调试

启动后先看以下几行：

```text
Connected read-only to KARDS pid ...
Auto voice: ON
Runtime objects: board=0x...; battle monitor=0x...
```

起手换牌界面出现时应显示：

```text
MatchState: OutsideMatch -> InMatch (active battle board and both HQ objects ready)
Opening hand ready: playing commander_intro.wav
```

打出己方手牌后应显示卡牌 ID、游戏原声音和识别类别，例如：

```text
Own card played: id=...
Card ...: definition=..., original sound=..., pool=TANK, ...
Card ...: pool=TANK, playing JP_TANK_...
```

若游戏的瞬时 ID 队列在两次读取之间已经清空，单位牌会显示补偿确认日志：

```text
Unit deployed from hand: definition=..., original sound=..., pool=TANK, side=...
Unit deployed from hand: pool=TANK, playing JP_TANK_...
```

若自动播报关闭，按一次 F9。F10 可随时确认当前运行状态。

每次运行都会把连接、开局、出牌分类、去重和结束事件写入程序旁边的：

`logs` 文件夹

若程序所在目录不可写，则改存到 `%LOCALAPPDATA%\KardsVox\logs`。

遇到某张牌仍未播报时，退出程序后保留最新的日志即可直接定位其内部卡牌名和触发路径。

其他检查命令：

```powershell
dotnet run -- --status
dotnet run -- --runtime-snapshot
dotnet run -- --smoke
dotnet run -- --self-test
```
