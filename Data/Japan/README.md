# 日本语音包台本 v1

这是 KardsVox 的**原创、架空战场对白**，采用二战日本军队与战时宣传的角色口吻；不把任何台词署名为历史人物的真实引述。日语是配音原文，中文是校对用意译。战时口号代表剧中角色的立场。

## 范围与现状

- [voice_lines.tsv](voice_lines.tsv) 是 144 条音频的索引。每一行是一条独立音频，`id` 对应 `Audio/Japan/<id>.wav`。
- 程序已加载本语音包。己方单位部署严格进入四个互斥池：步兵与炮兵、坦克、空军、海军。每个池完整洗牌后才重新开始，避免只反复抽中少数素材。所有指令牌进入独立指令池，并在语音前播放程序合成的电报码。
- 这份台本覆盖日本主国指挥官的局内事件，以及日方单位的步兵、装甲、炮兵、战斗机、轰炸机、海军声线，另有指令与反制。它是一套按事件与兵种复用的完整基础语音池；项目目前没有玩家的具体日本牌组清单，**没有声称给游戏内每一张日本卡单独写了专属台词**。盟国卡应使用其所属国家的声线。
- 日本卡的特定名称、卡牌效果与轮替名单会随游戏更新；接入专属卡牌语音时，用实际牌组导出清单校对后再扩充。本版刻意不把虚构效果绑定到具体卡名。

## 表格字段

| 字段 | 含义 |
|---|---|
| `id` | 音频文件名，不含扩展名。相同事件的 `_01`、`_02` 是随机备选。 |
| `voice` | 角色类别：`CMD` 指挥官；`INF_Y` 青年步兵；`INF_V` 老兵；`TANK` 车长；`ARTY` 炮兵；`FTR` 战斗机；`BMB` 轰炸机；`NAV` 海军；`OPS` 指令室。本批音频统一使用原“日军”模型，并非九套不同声线。 |
| `event` | 语义触发事件。不同声线同名事件可以共用触发器。 |
| `take` | 表演力度：`firm` 克制但强硬；`urgent` 急促；`shout` 吼叫；`solemn` 庄重。 |
| `ja` / `zh` | 日语录制文本 / 中文校对译文。 |

## 使用与表演

1. 开局用 `JP_CMD_INTRO_01` 至 `_04`，每局只抽一次；现为约 2–3 秒的短句。原版长句及音频备份在 `KardsVox.build/Backup/LongIntroOriginal`。若之后选历史人物声线，不要把原创对白标成其真实言论。
2. 普通选中、部署、移动控制在约 1–3 秒；怒吼留给进攻、HQ 危急、反攻及胜利。`shout` 要实际表演或用语音转换保留情绪，单纯给 TTS 加感叹号通常不够。
3. `DESTROYED` 是**我方单位被消灭**的最后一句；`KILL` 是**我方消灭目标**。单位死亡之后不再触发后续回应。`HURT` 只在受损且存活时播放。
4. `ORDER` 在我方指令生效时使用，`COUNTER` 在我方反制**实际触发**时使用；不能仅因卡片进入手牌而播放。`HQ_LOW`、`HQ_CRITICAL` 采用跨阈值触发并设每局冷却，避免连续吼叫。
5. 录音文件保持一句一文件，建议 WAV、48 kHz、单声道、16 位 PCM；文件名用 `id`，原始文本与音频一一对应。不要在同一声线训练集中混入别的演员。

## 风格约定

台词刻意带有「皇国」「勅命」「陛下」「軍旗」「玉砕」「七生報国」等战时用语，以纪律、献身、决死和帝国战争宣传构成鲜明角色性格。军官的宣传语和士兵的战斗口令有层次，避免每次点击都重复同一句口号。全稿为新写对白，不是 KARDS 官方配音，也不是任何历史人物的引语。

卡牌类别依据 [KARDS 官方卡牌说明](https://support.kards.com/hc/en-us/articles/360026768151-Cards)：单位、指令、反制；后续的实际触发应遵照[指令](https://support.kards.com/hc/en-us/articles/360026754851-Orders)和[反制](https://support.kards.com/hc/en-us/articles/360026404872-Countermeasure)的游戏规则。
