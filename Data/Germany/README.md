# 德国卡包 1.7.27

德国包提供德中字幕与 175 条录音。52 条单位语音按 26 条加强版、26 条原版混用，每个兵种事件池都包含两种力度。五段用户确认的传话筒开场、总部与逐卡指令保持原样。全包声音总时长 636.28 秒，分配详见 单位力度分配.tsv。

## 修改台词

只编辑两份表：`subtitle_lines.tsv`（开场、兵种、战况）和 `order_lines.tsv`（逐卡指令）。UTF-8，保留表头和真实制表符；不要在单元格放换行、制表符或编辑备注。改文案后重启程序。

`resource`、`category`、`trigger` 是固定键，不要随意更名。原句在上，中文在下。德国有步兵、炮兵、坦克、航空四种单位池，每种 5 条部署、3 条攻击、3 条受伤、2 条移动；5 段开场，3 条总部提示，115 条逐卡指令。舰船／潜艇资源在当前游戏中是指令，不按海军单位播报。

## 声音状态与后续修改

175 个 WAV 均与清单及现有转写记录的 SHA-256 一致；48 kHz、单声道、PCM 16 位，无缺项、截断、重复文件或数字削波。逐条时长见 `voice_generation_manifest.tsv`。加强版 26 条自动转写规范化后全部一致；全包保留 12 条旧录音转写差异，见建议复听清单；本次未进行母语逐条听审或游戏实战验收。

后续返修按 `声音素材清单.md` 或 `voice_generation_manifest.tsv` 的稳定文件名保存到 `Audio/Germany/`。每个文件只录制对应德文，不添加中文、前置惨叫、音乐或说明语。

修改台词后，用 Python 3 执行 `python Data/Germany/build_voice_manifest.py` 更新清单。它从两份台词表重建，不覆盖手改内容。可选的 `--command-json` 接受经人工验证的德语引擎命令参数数组；没有指定时只整理清单，不生成、不下载模型。原句修改后需重录对应文件。`format_ok_listening_pending` 仅表示格式通过，必须再试听。

缺文件标为 pending，损坏文件标为 invalid，都会退回字幕；启动不会因德国缺少声音失败。重启后自动识别已补齐的录音。声音与字幕分别开关；F6 会预览所选卡包。分段开场只补齐部分声音时，缺音片段按阅读时间保留间隔；程序不生成假录音。

## 目录与依据

`card_catalog.tsv` 是运行时资源与兵种映射；`card_titles.tsv` 提供当前游戏中／英／德牌名。`pack.json` 提供国家、语言、录音前缀和审核后的资源数。`asset_evidence.tsv` 记录实际卡种字节位置、牌效、本地化键、图像引用和资产哈希。

此次从 2026-09-26 本机 KARDS 当前包重新解包：德国目录 340 个资源，另纳入教程 4 个和特殊模式 1 个，共 345。包含 49 个总部／内部解锁资源，296 个非总部资源（181 单位、115 指令／反制）。这些数值不是官方可组牌总数，见 `coverage_report.md` 的统计范围和未确认项。

`order_review.tsv` 是游戏牌效审阅参考，不是另一份可编辑台词源。`sources.tsv` 标记所有台词为原创游戏对白，未冒充历史人物原话。德国包未引用政治口号。特殊资源的标题命名空间可能沿用其他国家，冲突均记录在核对文件中。

## 核对入口

运行 `KardsVox.exe --voice-check` 可检查三国数据、路由、缺音频与部分声音接入。实际 KARDS 对局检查另见交付报告；模拟测试不代表已完成实战验收。运行 `KardsVox.exe --runtime-snapshot` 需要 KARDS 正在运行。
