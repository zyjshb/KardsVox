# 芬兰卡包 · 1.7.26

44 项卡牌资源、20 条逐卡指令、80 条芬兰语录音和对应中文。指挥官开场五段共 21.08 秒，采用战前动员内容；音色参考用户提供的 `芬兰.wav`。

## 使用

选择“芬兰”后按 F6 试听指挥官。实际对局按每张牌的国家自动播报：芬兰单位与指令使用芬兰语。芬兰是盟国，当前没有芬兰总部；自动开场和总部警报仍跟随主国，F6 不改变这条规则。三条总部战况录音作为通用包兼容字段保留。

声音、字幕独立开关。80 个 WAV 全部接入；缺少或损坏个别录音时保留字幕。已有日、苏、德国包继续沿用原数据和录音。

## 只编辑这两份台词表

- `subtitle_lines.tsv`：5 段开场、3 条总部兼容字段，四个兵种各 5 部署、3 攻击、3 受伤、2 前移。
- `order_lines.tsv`：20 张指令／反制牌，一牌一行，原句与中文配对。

使用 UTF-8、真正的制表符，保留表头；不要修改稳定资源键或把说明放进台词。改中文后重启即可；改芬兰语原句后必须重生成同名 WAV，避免声音和字幕不一致。`voice_generation_manifest.tsv` 和 `声音素材清单.md` 是上述两表的派生清单，不能当作第三份编辑入口。

在便携目录运行 `python Data/Finland/build_voice_manifest.py` 可重建清单并检查 WAV 格式。模型推理及单条返修见 `generation_report.md`。每个 WAV 必须为 48 kHz、单声道、PCM16。

## 依据与验证

资源、现役／预备状态、逐卡画面和牌效核对见 `coverage_report.md`、`asset_evidence.tsv`、`official_status.tsv`、`art_review.tsv`。普通牌 43 项（32 项非预备、11 项预备），另有 SISSI 衍生牌 1 项；不把 44 项都称为可独立加入卡组的牌。

本机没有芬兰语官方本地化，英文标题与原创芬兰语台词明确区分。全部台词为原创游戏文案，不是历史引文。`audio_review.tsv` 保存逐条格式、电平、时长、转写和哈希；机器检查不代替母语试听。尚未完成母语者逐条听审和真实芬兰卡牌对局测试。
